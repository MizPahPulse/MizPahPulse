# Security Policy

## Reporting a vulnerability

Please report suspected security issues through GitHub's private vulnerability
reporting flow:

https://github.com/MizPahPulse/MizPahPulse/security/advisories/new

Do not open a public issue for a confirmed vulnerability.

## What to include

- Affected component or endpoint
- Steps to reproduce or a minimal proof of concept
- Impact and any mitigations you already applied
- Contact information for follow-up questions

## Response expectations

- Initial acknowledgment: within 72 hours
- Triage and impact assessment: within 7 days
- Coordinated disclosure: after a fix is ready or after 90 days without a
  resolution, whichever comes first

## Supported versions

Security fixes are applied to the latest stable release and the current
development branch. Older releases are not supported unless explicitly stated
in the release notes.
